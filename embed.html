A small, scored ranking list for your own site. One line of HTML, no signup, no scripts.

If you write about AI tools, run a newsletter, or keep a resources page for freelancers and solo founders, you're welcome to put the Solos Gems top 10 on your own site. What's on the list

The widget shows the ten highest-ranked tools in our database of 242, each with its score out of 10. Every score is the average of four things: value relative to price, real-world capability, ease of use and setup friction, and how safely you can try it before paying. It's one list across every category, so a design tool can outrank a meeting recorder if it simply delivers more for the money. Nothing has ever scored a 10. Tools we've tested hands-on are labeled Tested in the database; the rest are Scouted from public pricing and features. The full method is on our About page.

Each tool name links to that tool's row in the database, where readers can see what it costs, a cool fact about it, and the comic that goes with it.

Copy this code

<iframe src="https://solosgems.com/embed/top10" width="360" height="420" style="border:1px solid #423d34; border-radius:8px;" loading="lazy" title="Top 10 AI Tools for Solopreneurs"></iframe>

Paste that anywhere your site builder accepts raw HTML. A few common spots:

  • WordPress: add a Custom HTML block to a post, page, or sidebar widget area.
  • Ghost: use an HTML card in the editor.
  • Webflow: drop in an Embed element.
  • Squarespace: add a Code block.
  • Wix: use the Embed HTML (iframe) element.

Width and height can be changed to fit your layout. 360 by 420 pixels fits a typical sidebar; on a wider content column, try a width of 100% and a height around 440 so nothing scrolls. If your platform strips iframes from posts, the sidebar or a dedicated embed element usually still allows them.

Privacy and performance

The widget is a single small HTML page with no JavaScript, no cookies, no ads, and no analytics, so it won't slow your page down or add anything to your privacy policy. It loads lazily, which means browsers only fetch it when a reader scrolls near it.
