The Herald's Mailbag

Send word to the Herald

Three scrolls, one mailbag, zero carrier pigeons harmed

The Herald can only cry what reaches the town square. Found a tool the database is missing? Spotted one of ours that's wrong, renamed, or suddenly charging double? Watched an AI startup fall off the map? Pick a scroll below. A human reads every one, usually within a week, and nothing gets published without being checked against a real source first.

📜 Add a tool 🛠️ Fix a listing 💀 Report a death

That scroll arrived blank. Give the tool a name and try again.

📜 Add a tool to the database

Any AI tool real people can actually sign up for is fair game, not just ones for solo founders. If it makes the cut it gets a row, a summary, a cool fact, a comic, and a caption. Tools that earn a spot in the ranked 51 get the full gauntlet and a score out of 10.

🛠️ Fix a listing

AI tools change prices, names, and entire personalities overnight. If a row in the database is out of date, tell us what changed and, ideally, where you saw it. Building one of these tools? Corrections from the makers are very welcome.

💀 Report a death for the DeathStack

Know an AI tool or service that shut down, got acquired and switched off, or quietly stopped answering the door? Nominate it for the DeathStack. We only bury what we can source, so a link to a news story or the official goodbye post helps a lot.
