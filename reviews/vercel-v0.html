Pricing breakdown

  • Free: $5 of included monthly credits, 7 messages/day limit, deploy apps to Vercel, visual Design Mode, GitHub sync
  • Plus ($30/user/mo): $30 of included monthly credits per user, access to all models, $2 of free daily credits, team chat sharing and centralized billing
  • Business ($100/user/mo): Same credit allowance as Plus, training opt-out by default
  • Enterprise (custom pricing): SAML SSO, role-based access control, priority performance, guaranteed support SLAs

Why this is different from a chatbot that writes code

The output isn't a code snippet to copy into your own project, it's a working, deployable app with a live preview, editable visually through Design Mode, and synced to GitHub so you can keep working on it in a real codebase. For a solopreneur building their own product's interface without hiring a frontend developer, that's a meaningfully shorter path from idea to a working prototype than pasting generated code into a blank project by hand.
